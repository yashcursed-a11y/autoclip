A FEW THINGS, BEFORE YOU BEGIN.

Is this the actual app?

This is the AUTOCLIPIN product website. The clip wall and launch interaction use sample footage. Open the desktop app to import, edit and export your own videos.

Does “hack the algorithm” guarantee views?

No. It’s our creative rallying cry. AUTOCLIPIN helps you make clips; audience growth, reach and income depend on your content and many other factors.

What do I need to run it?

A Windows computer. Check the latest release for setup instructions, local tools and model requirements. Video links and connected services need an internet connection.

How do downloads stay up to date?

The download button checks the latest stable published GitHub release. Drafts, prereleases and unfinished builds aren’t selected.

Need a hand?

Report a bug or request a feature through GitHub Issues, with your app version and what happened.
